# Pocket Web SDK

This repository is the binary distribution channel for Pocket Web SDK and Pocket Editor.

The first public binary release is intentionally pending until the TFTC package is complete and included. Release ZIP files will contain precompiled platform tools, the WebAssembly runtime, compiled JavaScript packages, type declarations, runtime assets, documentation and checksums. They will not contain the SDK's TypeScript, JavaScript implementation, Rust or Flutter/Dart source code.

Consumers will not need Flutter, Rust or LLVM to install the released SDK. Application JS/TS remains consumer-owned input and is compiled by the packaged build tool.

Source development continues in the private/maintainer source repository. Do not use this distribution repository as a source checkout.
